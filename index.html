PROJECT & DEVELOPMENT

Built for a more resource-conscious campus.

MCC ReLoop is a campus reuse platform created to help useful items find their next home. By making it easier for students to share, exchange and reuse, the project encourages responsible resource use and helps reduce avoidable waste within Madras Christian College.
